# The Invitation, Unveiled

Christian James Caguioa and Dana Cheyenne Cornita are planning a February 6, 2027 seaside wedding in Caba, La Union. The website follows a single cinematic scroll from champagne silk to golden-hour shoreline. The approved direction combines cinematic romance with warm coastal elegance.

| Scene | Focus |
| --- | --- |
| 01 · The Unveiling | Champagne silk and the invitation inscription |
| 02 · A Moment in Time | Monochrome couple portrait |
| 03 · Written in the Stars | Calligraphy and botanical paper |
| 04 · Forever Begins | Ring and ceremony timing |
| 05 · Where We Say I Do | Coastal venue and directions |
| 06 · With Our Families | Parents and principal sponsors |
| 07 · Standing Beside Us | Entourage |
| 08 · The Wedding Palette | Fabric swatches and attire |
| 09 · A Few Loving Notes | Guest policies, gifts and after-party |
| 10 · An Invitation to Respond | Envelope and RSVP |
| 11 · Until We Meet | Golden-hour farewell |

Portrait mobile leads the composition, with short native-scroll sequences and safe-area spacing. Desktop adds lateral stage depth. Keep guest details readable and make key shortcuts reachable as those sections are approved.

Use the existing React 19, Vite 8, Tailwind 4, GSAP 3, React Router 8 and strict TypeScript setup. Reserve 3D dependencies for a scene that needs geometry. The site is frontend-only. RSVP collection and the venue map pin need decisions or verification before those scenes. Couple and venue photography require approval and asset registration. Review the invitation transcription against the originals before release.
